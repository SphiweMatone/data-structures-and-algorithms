# Graph Traversal Visualizer

A simple browser-based visualizer for Breadth-First Search (BFS) and Depth-First Search (DFS).

## What it demonstrates

- BFS explores nodes level by level using a queue.
- DFS explores as far as possible along one path before backtracking.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open `index.html` in a browser.

## Why I Built This

I built this project to make graph traversal easier to understand visually instead of only reading code.
