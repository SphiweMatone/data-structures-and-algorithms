# Depth-First Search (DFS)

## What is DFS?

Depth-First Search is a graph traversal algorithm that explores as far as possible along one path before backtracking.

## Approach

- Start from a node
- Mark it as visited
- Recursively visit each unvisited neighbor

## Key Idea

DFS goes deep before it goes wide.

## Time Complexity

- O(V + E)

## Space Complexity

- O(V)

The space comes from the visited set and the recursive call stack.
