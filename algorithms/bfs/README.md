# Breadth-First Search (BFS)

## What is BFS?

Breadth-First Search is a graph traversal algorithm that explores nodes level by level.

## Approach

- Use a queue to track nodes
- Mark nodes as visited to avoid cycles
- Process nodes in FIFO order

## Key Idea

BFS explores all neighbors of a node before moving deeper into the graph.

## Time Complexity

- O(V + E)

## Space Complexity

- O(V)
